# Production quality control — Ninety Sense / American Wallet

Run this checklist against the actual rendered MP4, not just the storyboard. The selected format is per production and applies equally to both channels.

## Project setup and format
- [ ] Correct channel profile is loaded: Ninety Sense or American Wallet.
- [ ] Exactly one format was selected for this production: 16:9 landscape or 9:16 portrait.
- [ ] Export dimensions and aspect ratio match the selected format.
- [ ] Scenes, assets, charts, captions, subtitles, graphics, and safe areas were composed for the selected format from the beginning.
- [ ] No blind crop, stretch, or letterbox was used to convert a composition made for the other format.
- [ ] No second format was rendered unless it was requested as a separate production.

## Filename and delivery
- [ ] Original uploaded voiceover filename was read from upload metadata.
- [ ] Final MP4 basename matches the original voiceover basename exactly; only the final audio extension was replaced with lowercase `.mp4`.
- [ ] Numbering, capitalization, spaces, punctuation, hyphens, and underscores are preserved.
- [ ] No title, channel name, date, format, version, or "final" suffix was added.
- [ ] Exported file exists, has the required name, and opens in a media player.
- [ ] If a same-name file already existed, no file was silently overwritten or renamed to evade the collision.

## Picture and edit
- [ ] Complete timeline was inspected with narration playing.
- [ ] Every narration beat has an intentional, story-relevant visual treatment.
- [ ] No unintended black frames, frozen frames, missing media, default backgrounds, placeholders, or broken transitions remain.
- [ ] Shot progression, pacing, continuity, and transitions support the actual story.
- [ ] Important text, faces, documents, and action remain inside the selected format's safe areas.
- [ ] Subtitles are checked against the actual audio and remain readable.
- [ ] The opening earns attention and the ending pays off the video's promise.

## Voice and sound
- [ ] Voiceover is synchronized from first word to last word; no sentence or syllable is cut off.
- [ ] Voice remains clear and natural, without clipping, distortion, accidental silence, or abrupt edits.
- [ ] Music has a story-specific arc and does not mask narration.
- [ ] Ambience, foley, effects, transitions, and sound bridges are purposeful and synchronized where used.
- [ ] No random effects, repetitive whooshes, or unnecessary sound layers clutter the mix.
- [ ] Fades, crossfades, ducking, and level changes are smooth.
- [ ] Loudness and true peak are measured only if the available tools actually measured them; never claim unperformed measurements.

## Ninety Sense visual checks
- [ ] The original Ninety Sense visual identity is followed; do not copy another creator's exact characters, artwork, footage, music, or branding.
- [ ] When the 3D environment + expressive 2D face system is used, the two styles are intentionally integrated.
- [ ] Recurring characters maintain proportions, outfit, colors, face treatment, and continuity.
- [ ] Eyelines, screen direction, prop positions, and action continuity make sense between cuts.
- [ ] Every visual beat expresses the narration; no generic filler shots.
- [ ] The reveal is understandable and the ending pays off the opening.

## Ninety Sense typography and color checks
- [ ] Deep Ink (`#111827`), Slate (`#374151`), Warm Ivory (`#F7F4EE`), Muted Vermilion (`#C94B3C`), Soft Sand (`#E8DED0`), and White (`#FFFFFF`) are used consistently.
- [ ] No purple, neon blue/cyan, gradients, glow, rainbow colors, or excessive red.
- [ ] Oswald Bold (700) is used for short hooks/key phrases and Manrope for subtitles, captions, and supporting labels, unless a documented fallback was necessary.
- [ ] Typography is selective and mobile-readable; text does not cover expressive faces, important props, or story action. No forced text on every shot.
- [ ] The canonical Ninety Figure and cube references are preserved exactly when supplied.

## American Wallet visual checks
- [ ] Barlow Condensed ExtraBold is used for display headlines and primary financial figures, unless a documented font-availability fallback was necessary.
- [ ] Inter is used for supporting copy, chart labels, captions, and subtitles, unless a documented fallback was necessary.
- [ ] Thumbnail headline uses the approved uppercase text-only treatment: Warm Ivory on Deep Navy, without boxes, outlines, shadows, or decorative extras.
- [ ] Kinetic typography is selective, narration-synchronized, and improves comprehension rather than animating every word.
- [ ] Font roles, weights, hierarchy, and legibility remain consistent across the selected aspect ratio.
- [ ] Finance-documentary identity is maintained; the result is not an unrelated stock-footage slideshow or audio over a blank screen.
- [ ] Deep Navy (`#14263D`) and Warm Ivory (`#F5F1E8`) remain the permanent American Wallet brand foundation.
- [ ] Muted green is used only for a contextually positive financial outcome; muted red only for a contextually negative outcome. An increase in debt/costs is not treated as positive, and a decrease in debt/expenses is not treated as negative by default.
- [ ] Red/green are restrained informational signals, not decorative brand colors; neutral explanations remain navy/ivory or subdued neutrals.
- [ ] Charts and comparisons include labels, symbols, or direction cues so meaning is not communicated by color alone.
- [ ] Financial numbers, charts, and documents match the supplied script or approved source assets.
- [ ] No invented account balances, statistics, government forms, headlines, or official-looking evidence.
- [ ] Documentary scenes, people, maps, diagrams, timelines, and typography genuinely explain the financial story.
- [ ] Older viewers can read on-screen text and understand charts on a phone.
- [ ] Supplied host reference identity is preserved if the host is used.
- [ ] Finance remains the subject even when politics provides context.

## Final playback review
- [ ] Watch the complete export once at normal speed.
- [ ] Check the beginning, middle, ending, and any visually or sonically complex transitions.
- [ ] Confirm the final sentence and final visual resolve cleanly.
- [ ] Confirm the delivered file is the inspected export, not an earlier render.

## Delivery truth
Only check an item after inspecting the actual output. If the current environment cannot render, open, listen to, or inspect the file, report that exact limitation. Never mark an unverified item complete or claim a finished export without an actual MP4.
