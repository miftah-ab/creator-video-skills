# Production pipeline reference

This reference expands the main skill. It is a decision framework, not a rigid template.

## Scene selection logic

Choose the visual form that best communicates each beat:

| Story need | Useful visual forms |
|---|---|
| Explain a system | Animated diagram, map, labeled sequence, process visualization |
| Prove a claim | Source document, chart, comparison, highlighted figure |
| Make an abstract feeling tangible | Visual metaphor, symbolic object, environment, human detail |
| Establish stakes | Scale, contrast, consequence, specific real-world setting |
| Build suspense | Partial reveal, controlled movement, negative space, restrained sound |
| Show change over time | Timeline, before/after, progressive chart, changing environment |
| Make a personal moment human | Character, hands, face, domestic detail, observed behavior |
| Deliver a payoff | Return to an earlier motif with a changed meaning |

## Visual quality rules

- Prefer specific, story-relevant images over generic filler.
- Each visual should add information, emotion, or orientation.
- Avoid repeating the same shot type for consecutive scenes unless repetition is deliberate.
- Use a recurring visual motif when it helps the viewer follow the argument.
- Do not put long paragraphs on screen.
- Use charts only when the data is known and the chart makes the point clearer.
- Never invent financial statistics, quotations, studies, news, or source documents to make a scene look credible.
- If a visual is illustrative rather than documentary evidence, do not present it as real evidence.

## Asset decisions

1. Check user-supplied assets first.
2. Check genuinely available free/local tools and libraries.
3. Create original graphics and motion when practical.
4. Use image/video generation only if a suitable capability is actually available in the current Claude environment and does not require a paid API.
5. If none is available, create a clear production plan and mark assets that still need sourcing.

## Sound cue design

Use cue categories sparingly:
- Texture: room tone, wind, distant city, paper, machinery.
- Action: clicks, footsteps, object handling, switches.
- Transition: restrained riser, low impact, tonal shift.
- Emotional punctuation: subtle bass, pulse, silence, restrained hit.

Every cue must have a reason and a timing point. Do not stack multiple effects just because a scene changes.
