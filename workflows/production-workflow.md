# Production workflow

## Normal user handoff

The user supplies:
- Final script.
- Matching voiceover audio.
- Channel and aspect ratio only if not already clear from the conversation.

Claude owns:
- Input validation.
- Story interpretation.
- Audio-led timing.
- Scene design.
- Visual and motion decisions.
- Text/subtitle plan.
- Music and sound-effect decisions.
- Editing/rendering where supported.
- Quality control and delivery.

## Default decisions

- Story determines the visual treatment.
- Voiceover determines timing.
- Use both channels' profiles as separate identities.
- Support 16:9 and 9:16 as independent compositions.
- Prefer free available tools; do not assume paid APIs.
- No approval checkpoints unless a genuine blocker or irreversible decision exists.

## Honest fallback

If Claude cannot render in the current environment, it must not claim it has produced a video. It should deliver a complete production package with:
- Timestamped scene plan.
- Visual descriptions and prompts.
- Motion and transition instructions.
- Subtitle and emphasis-text plan.
- Music and sound-effect cue sheet.
- Asset checklist.
- Assembly/export instructions for the available editor or tool.

## Iteration

After each completed video, review:
- What improved viewer understanding?
- Where did pacing or retention weaken?
- Which visuals felt generic or repetitive?
- Were text and sound timed correctly?
- What should become a reusable channel rule?

Only promote lessons supported by actual review into the skill or channel profile.
