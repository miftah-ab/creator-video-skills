# Shared assets

Place only reusable, properly licensed assets here.

Suggested organization:
- `music/` — background music and stems.
- `sound-effects/` — reusable effects and ambience.
- `visual-references/` — approved style references, not assets to copy.
- `fonts/` — fonts with redistribution rights.

Do not commit huge media libraries to Git. Add a small curated starter set first, and keep a separate inventory file with filename, source, license, attribution requirement, and intended use.

Claude must not assume any asset exists merely because a folder is present. It must inspect the actual supplied files.
